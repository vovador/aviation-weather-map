# Aviation Weather Map Frontend

React frontend for visualizing SIGMET and AIRSIGMET aviation weather data on an interactive map.

## Quick Start

1. Install dependencies:

```bash
npm install
# or
yarn install
```

2. Create `.env` file:

```env
VITE_API_BASE_URL=http://localhost:4000
```

3. Start development server:

```bash
npm run dev
# or
yarn dev
```

App runs at `http://localhost:5173`

## Commands

- `npm run dev` / `yarn dev` - Start development server
- `npm run build` / `yarn build` - Build for production
- `npm test` / `yarn test` - Run tests
- `npm run test:ui` / `yarn test:ui` - Run tests with UI

## Tech Stack

React 18, TypeScript, Vite, Redux Toolkit, MapLibre GL JS, TailwindCSS
